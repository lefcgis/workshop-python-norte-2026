# 🎓 Módulo 2 — Didática do SIG na Sala de Aula Universitária

**Workshop Docentes: Geoprocessamento na Amazônia**

---

## 2.1 O SIG como Ferramenta Pedagógica

Incorporar o SIG na sala de aula universitária não se resume a ensinar um software. Implica **desenvolver o pensamento espacial** como competência disciplinar da Geografia.

### Dimensões do pensamento espacial a desenvolver:

| Dimensão | Pergunta orientadora | Ferramenta SIG |
|---|---|---|
| Localização | Onde está X? | Coordenadas, busca de feições |
| Distribuição | Como X está distribuído? | Mapas de densidade, coropletas |
| Padrão | Qual é a forma do fenômeno? | Análise de cluster |
| Relação | Como X se relaciona com Y? | Sobreposição, correlação espacial |
| Mudança | Como X evolui no tempo? | Análise multitemporal |

---

## 2.2 Estratégias Didáticas Recomendadas

### A. Modelagem do Docente (Eu Faço / I Do)
- O docente realiza a análise passo a passo com a tela projetada
- Verbaliza seu raciocínio: *"Escolho esta projeção porque..."*
- Mostra também os erros comuns e como resolvê-los

### B. Prática Guiada (Nós Fazemos / We Do)
- Os estudantes replicam a análise seguindo as instruções
- O docente circula e oferece suporte diferenciado
- Estudantes mais avançados podem apoiar quem tiver dificuldades

### C. Prática Independente (Você Faz / You Do)
- Variações do problema para que os estudantes apliquem sem guia
- Projetos próprios com dados reais
- Reflexão metacognitiva: *O que eu aprendi? O que foi difícil para mim?*

---

## 2.3 Gestão do Laboratório de Informática

### Problemas comuns e soluções:

| Problema | Solução |
|---|---|
| QGIS não abre / erro de instalação | Ter instalador no pendrive, testar 1 dia antes |
| Projeção incorreta nos dados | Ensinar a identificar e reprojetar desde o início |
| Dados muito pesados, download lento | Baixar previamente os dados e mantê-los em servidor local |
| Estudantes com ritmos muito diferentes | Atividades de extensão para quem avança rápido |
| Frustração com Python | Python é opcional; o QGIS sozinho é suficiente |

## 2.4 Integração de Temas Transversais

O workshop pode ser vinculado a temas transversais do currículo de Geografia:

```
🌿 AMBIENTAL:
   → Mudanças climáticas, desmatamento, biodiversidade

⚖️ DIREITOS HUMANOS:
   → Direitos territoriais indígenas, justiça ambiental

🌎 GEOPOLÍTICA:
   → Soberania amazônica, governança transfronteiriça

📊 ESTATÍSTICA:
   → Análise quantitativa, índices, estatística espacial

💻 DIGITAL:
   → Competências digitais, dados abertos (opendata), acesso aberto
```

---

## 2.5 Adaptações para Diferentes Contextos

### Para contextos com recursos limitados:
- Usar **QGIS portátil** (sem instalação) a partir de um pendrive
- Trabalhar com dados **previamente baixados** para evitar dependência de internet
- Priorizar **módulos 1 e 2** se o tempo for limitado

### Para contextos com mais recursos:
- Incorporar o **Google Earth Engine** (nuvem)
- Usar **tablets com QField/Mergin Maps** para coletar dados de campo
- Integrar o workshop com uma **saída de campo** real

### Para modalidade totalmente virtual:
- Usar **Google Meet/Zoom/Teams/Jitsi** com compartilhamento de tela
- Preparar **tutoriais em vídeo** para cada geoprocesso no QGIS
- Criar um **fórum de dúvidas técnicas** no AVA (Ambiente Virtual de Aprendizagem)
- Disponibilizar um servidor de dados acessível a todos

---

## 2.6 Momentos de Metacognição

Incorpore estas perguntas em cada sessão para incentivar a reflexão:

**No início:**
> O que já sei sobre este tema? Quais dúvidas eu tenho?

**Durante a prática:**
> Por que estou fazendo esta etapa? O que aconteceria se eu escolhesse outro caminho?

**No encerramento:**
> O que aprendi hoje? Como posso usar isso no meu próprio trabalho de pesquisa?
